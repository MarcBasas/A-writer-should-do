# 维度6：生成约束与编辑校验

> 所属指导集：write-like-lijieren（基于《死水微澜》）
> 执行顺序：第6步 / 共6步
> 前置依赖：维度1-5全部完成（成稿初稿已产出）
> 合并自：原反AI检测机制 + 原编辑层 + 反模仿伦理

本维度不改写风格，只回答三个问题：**初稿哪里像AI？哪里不像李劼人？哪里该删？**

## A. AI典型问题检测（全局黑名单，逐条校验）

> 优先级最高：写作完成后先过本节，触发任一条即须改写。黑名单为全局强制，所有篇目一律适用。

**A. 句式黑名单**

| 编号 | 禁止的AI典型句式 | 具体表现 | 替代策略 |
|:---:|---|---|---|
| A1 | 三段式排比 | "A在...；B在...；C在..."三段并列（如"刷短视频在讲...；翻开书在讲...；开个会在讲..."） | 用一句直白概括替代，或只保留一个具体场景 |
| A2 | "不是A而是B"对比结构 | "不是...而是..."的对比句式推进论点 | 用直接陈述或具体经验替代 |
| A3 | 设问自答式推进 | "为什么...呢？因为..."的自问自答（除非原作者频繁使用且通过频次验证；注意：李劼人的"自问链"是人物追问自己且往往答不出，与此不同） | 用直接陈述或场景叙述替代 |
| A4 | 工整对仗式总结 | "把A当成B""将A化为B"的对称总结句 | 用口语化直白表达替代 |
| A5 | 过渡词模式化 | 每段开头都用"当然""不过""反过来说""说到底"等过渡词 | 过渡词须分散使用，至少30%的段落无过渡词直接跳跃 |
| A6 | 拟人化修辞 | "胃开始抗议""时间在流逝"等AI式拟人 | 用直接身体感受替代（如"胃开始不舒服"）；李劼人式通感例外，见维度7 |
| A7 | 伪亲切模式 | 滥用"你"制造代入感（"你是否也...""你有没有..."） | 用第一人称经验替代；李劼人的"你"仅用于风物志段引导视线（见维度2） |
| A8 | 故作轻松语气 | "就这么简单""其实很容易""没什么大不了" | 用真实的困难描述替代 |
| A9 | "不"字定义法 | 用"不+形容词"定义或判断（如"不简单""不容易""不一般"） | 用具体描述替代（如"需要反复尝试""花了三个小时"） |
| A10 | 强制因果句式 | "正是因为...所以...""由此可见...因此..."的显性因果链 | 用语义自然承接替代，省略因果连接词 |
| A11 | "短直简"速记式描写 | 用极短的致使结构直接给身体或环境派发一个状态，或用模糊物件、省略状态主体，没头没尾，如"照得人脸上发青""让空气凝固""把东西攥在手里，攥得发白"（不说东西是什么，也不说什么发白）——不含具体过程与体验细节，也不承担叙事功能（既不坐实前句的判断，也不推进情绪） | 把物件写具体、给状态补上主体（如"把她娘带的那包吃的抱在怀里，她娘走出老远了，她还站在那儿抱着"），或替换为具体的身体/体验后果（如"一天下来衣裳都是湿的，脱下来能拧出水"），无必要时直接删除 |
| A13 | 句尾顿悟点评与缀饰 | 叙述或描写完成后，在句尾追加极短的论断、感悟或修饰，形成事实加顿悟、描写加缀饰的两段式，如两样钱都黑、一个馒头比天大、眉毛蜷起来像烧过的纸、手黑得发亮、吃得脸都肿——细节被强行点化成寓言，描写被强行拔高成抒情，是最高频的AI腔痕迹；同禁无叙事功能的过短状态句 | 默认整句删除句尾顿悟与缀饰，叙述在事实本身处停止；若该句承担伏笔或人物刻画等叙事功能，改写为具体过程、动作或台词，不得以独立短论断句的形式保留 |

**B. 用词黑名单**

| 编号 | 禁止的AI典型用词 | 具体词汇 | 替代策略 |
|:---:|---|---|---|
| B1 | 精致书面词汇 | "信誓旦旦""固有认知""终极武器""毋庸置疑""由此可见""综上所述""不言而喻" | 用日常口语化表达替代 |
| B2 | 对冲语气词过度使用 | "似乎""或许""大概""应该""可能"每篇超过3次 | 控制在2次以内，或用确定性表达替代；注意：李劼人叙述层"大概/似乎"作史官揣测口吻使用时除外，须与人物对话层区分 |
| B3 | 模糊代词 | 用"东西""活""事"代替具体名词 | 用精确名词替代 |
| B4 | 单字形容词 | "腻""响""空""窄""快""大"等单字形容 | 用完整短语替代（如"声音很大"而非"很响"）；李劼人式叠词（"黄焦焦""笑嘻嘻"）不在此列 |
| B5 | AI式刻意口语 | "跳脚""兜不住""挺久""还行""一圈""一堆""有货""有坑" | 用自然口语替代 |
| B6 | 空洞断言词 | "迟早""必然""一定会""终将" | 用具体条件限定替代（如"在...的情况下，可能会..."） |
| B7 | 精致形容词堆砌 | "深刻的""本质的""核心的""关键的"连续出现 | 每篇此类词不超过2个，用具体描述替代 |
| B8 | "某种程度上"式模糊限定 | "某种程度上""在一定意义上""从某种角度" | 直接删除或用具体程度替代 |

**C. 结构黑名单**

| 编号 | 禁止的AI典型结构 | 具体表现 | 替代策略 |
|:---:|---|---|---|
| C1 | 完整起承转合 | "引入→经历→案例→辩证→总结→收束"的完整对称结构 | 须允许结构松散、过渡突兀、结论松散 |
| C2 | 过于平滑的段间过渡 | 每段开头都与上一段自然衔接 | 须有至少2处跳跃或断层 |
| C3 | 均匀段落分布 | 所有段落长度相近（每段3-5句） | 须有单句成段与3-5句正常段落的交错，单句成段占比≥20% |
| C4 | 对称论证 | 论据与结论完美匹配，每个论据都指向同一结论 | 须允许某些论据指向模糊结论，或某些结论缺乏充分论据 |
| C5 | 过度类比 | 为每个观点都构造一个比喻 | 比喻数量控制在每篇1-2个 |
| C6 | 信息均匀分布 | 每段信息密度相近 | 须制造信息不对称：某些段落密度极高，某些段落几乎无信息 |

**D. 质感黑名单**

| 编号 | 禁止的AI典型质感 | 具体表现 | 替代策略 |
|:---:|---|---|---|
| D1 | 过度类比 | 为每个观点构造比喻（如"名牌T恤""捷径的通行证"） | 比喻须从个人经验自然生发，非刻意构造 |
| D2 | 伪亲切代入 | 滥用"你"制造代入感（"你是否也有过...""你想过没有..."） | 用"我"的第一人称经验替代 |
| D3 | 故作轻松 | "就这么简单""其实很容易""没什么大不了" | 用真实困难描述替代 |
| D4 | 总结式收束泛滥 | 每篇都以"说到底""归根结底"式总结收束 | 收束方式须多样化，允许松散结尾 |
| D5 | 完美论证 | 每个论点都有充分论据，逻辑无懈可击 | 须允许至少1处论证留白或逻辑跳跃 |

## B. 文学真实性检查（李劼人专项）

- [ ] **是否复制作者表面语言**：新作中不得出现原文句子、原文人物、地名与情节；句式骨架套用原文再填词同样禁止（种子文本仅作结构参照）
- [ ] **是否缺少真实细节**：每个场景须有时间、地点、人名或具体物件锚点（E3）；通篇"某个人""一件事"式占位符即为失败
- [ ] **是否只有风格没有世界观**：删掉风格化措辞后，文本是否仍有李劼人式的判断方式与价值立场；若只剩腔调，回到维度1、维度2重建
- [ ] **人物台词真实性**（虚构文体适用）：每个人物只说符合其身份、处境、利益的话；禁止人物替主题代言（主题词借壳）、禁止给人物配滴水不漏的金句回击（黑名单A12）

## C. 编辑校验三问（成稿后逐段执行）

1. **删除什么？**
   - 删解释：情绪与结论已由场景呈现处，删去解释性句子（作者不替读者总结）
   - 删过渡：段间靠语义承接即可处，删去"当然""不过""说到底"式过渡词（全篇过渡词段落占比≤70%）
   - 删金句：独立成段的警句若删掉不影响文意，直接删或并入上下文
   - 删冗余修饰：连续两个以上形容词修饰同一名词时保留一个
2. **哪里应该停顿？**
   - 重大变故（死亡、背叛、幻灭）之后须留一个停顿：单句成段、空一行、或切到无关的日常动作
   - 判断句出口后不立即补充论据，允许读者先悬在半空
3. **哪里应该留白？**
   - 结尾禁止总结升华，按李劼人的收束习惯戛然而止（见维度3）
   - 人物动机写出七分即可，剩下三分交给行为本身
   - 最痛处不写"痛"字，用动作与物件替代（见维度5情绪表达规则）

## D. 人写模拟技术（全局强制，逐项落实）

> 以下8项技术主动注入"人写"特征，与A节黑名单互补。李劼人风格下的落实要点已在各项中注明。

| 编号 | 技术 | 具体操作 | 量化要求 |
|:---:|---|---|---|
| E1 | 思维跳跃注入 | 在叙事中途插入1-2处看似无关的掌故联想（如由镇名来历、器物由来讲起），再拉回主线 | 每篇至少1处 |
| E2 | 质量不均制造 | 故意让1-2个句子写得"粗糙"或"不够好"，保持人类写作的不完美感 | 每篇至少1句口语化碎句 |
| E3 | 具体到不能再具体的细节 | 用"花了四个钱一两买来的哩"替代"买了条贵鱼"；物价、斤两、路程、名号写足 | 每篇至少2处具体细节 |
| E4 | 允许跑题 | 在主线之外有1-2句话的偏离（如交代一个配角的来历），然后自然拉回 | 每篇至少1处跑题 |
| E5 | 信息不对称制造 | 某些段落信息密度极高（清单式罗列），某些段落几乎无信息（纯场景、纯天气） | 全文信息密度差异≥3倍 |
| E6 | 个人语言怪癖复现 | 从原文中提取的特定用词（"据说""大概""何尝""业已""啥子""咋个"）在写作中高频复现 | 每篇至少3次复现 |
| E7 | 体验性细节优先 | 用主观判断、日常动作、身体感受、验证行为替代抽象环境描述 | 体验性细节占比≥60% |
| E8 | 句长极差制造 | 确保全篇最短句（5字以内，如"没有回答。"）与最长句（40字以上清单句）的长度差超过35字 | 句长标准差≥15 |

## E. 叙事逻辑自检（独立于风格校验，初稿后强制执行）

风格蒸馏只覆盖文风的统计特征，不覆盖叙事逻辑一致性。初稿完成后逐项检查：

- [ ] ①人物称谓与排行辈分一致（谁称谁哥/弟/姐，前后不得错乱）
- [ ] ②对话内部无自相矛盾（不得前句问价、后句质疑收钱式错位）
- [ ] ③机构名称、证件有效期、办事程序等设定全文一致
- [ ] ④时间、年龄、金额前后自洽

## F. 反模仿伦理

- **模仿解释世界的方法，不复制作者的经历**：不得把作者的真实生平、亲友、事件搬进新作；提取的是视角与判断方式，不是素材
- **像李劼人≠是李劼人**：新作的世界观落点允许与原作不同，但观察与判断的"方法"必须一致
- **禁止风格炫技**：不得为展示"像"而堆砌作者标志性句式；每篇标志性句式复现以维度4的频次门槛为限
