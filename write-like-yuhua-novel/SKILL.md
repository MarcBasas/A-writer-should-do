# 写作指导：余华小说风格（基于《活着》）

## 适用场景

本指导适用于需要模仿余华小说写作风格的创作任务，包括但不限于：小说续写、仿写、风格化改写、风格校验。指导基于单本《活着》提取，覆盖该书的长篇小说写作特征，未涵盖余华其他作品（《许三观卖血记》《兄弟》《文城》等）的风格变化。与基于散文集《我们生活在巨大的差距里》的 write-like-yuhua（散文版）并存：小说创作任务一律使用本 Skill。

## Literary DNA Summary

> **最高优先级参考**：写作前必读。与维度文件冲突时，以本摘要的精神为准。

**1. 如何看世界**：生存本位——人是为活着本身而活着，苦难不产生教训也不产生意义；叙述者必须是当事人，语气自嘲、认命、带笑，把最惨的事讲得像家常。
**2. 如何选择人物**：只选被时代碾过的底层小人物（农民、妓女、队长、老兵）；人物说话必须粗粝带土，身份即语言。
**3. 如何处理痛苦**：死亡用一句平静陈述完成（"过了没多久就死了"），悲痛全部外化为动作；最惨烈的段落旁边允许挂着粗俗的民间幽默，凄与谐突转不做过渡。
**4. 核心表达机制**：白描为骨（比喻稀少且取材乡间日常）；死亡写得极短、死亡前后的日常写得极细；民间因果、行为先于心理；结尾落在日常动作或田野空镜头上。
**5. 生成时最需避免**：议论抒情与呼天抢地；苦难升华出哲理；精致书面词；死亡大段渲染；人物说主题词（黑名单A12）。

## 一、风格总纲

1. **冷峻克制**：死亡与苦难用平静陈述完成，禁止呼天抢地、禁止议论抒情，情绪全部外化为动作与景物。
2. **民间言说**：叙述者必须是当事人（第一人称回忆体或框架叙事中的讲述者），语气自嘲、认命、带笑，把最惨的事讲得像家常。
3. **白描为骨**：人物、场景、死亡一律素笔勾画，比喻稀少且必须取材乡间日常（盐、柴禾、灯笼、蚊子、泥路）。
4. **凄谐并置**：最惨烈的段落旁边允许挂着粗俗的民间幽默，情绪在凄与谐之间突转，不做过渡。
5. **拒绝升华**：苦难不产生教训，结尾落在日常动作或田野空镜头上，禁止哲理总结。

## 二、执行顺序与文件索引

写作时须按以下顺序依次加载并执行六个维度文件。顺序遵循「定神→立意→布局→炼语→施技→校稿」的递进逻辑，前序维度的决策构成后续维度的约束前提：

| 执行顺序 | 文件 | 维度 | 职责 | 依赖前提 |
|:---:|---|---|---|---|
| 1 | `01-author-spirit.md` | 作者精神模型 | 确立冷峻克制基调、民间第一人称立场、凄谐情绪底色 | 无（最先执行，为全文定调） |
| 2 | `02-theme-worldview.md` | 母题与世界观 | 确定忍受母题、底层素材、历史侧写原则 | 依赖维度1确立的精神底色 |
| 3 | `03-narrative-mechanism.md` | 叙事结构机制 | 规划框架叙事/死亡链结构、首尾锚点、时间硬切与详略倒置 | 依赖维度2确定的母题与立场 |
| 4 | `04-language-rhythm.md` | 语言节奏系统 | 控制农民口语词汇、短句连缀、死亡密度倒挂的节奏 | 依赖维度3确定的结构框架 |
| 5 | `05-expression-and-space.md` | 表达技法与留白 | 选择白描、民间比喻、歌谣意象、黑色幽默与留白 | 依赖维度4确定的词句节奏 |
| 6 | `06-generation-editor.md` | 生成约束与编辑校验 | AI检测、真实性检查、编辑三问、叙事逻辑自检、反模仿伦理 | 最后执行，初稿成形后终检 |

### 执行方式

- **产出落盘**：写作产出须按母 Skill「写作产出落盘」规则执行，成稿以 `{文章标题}.md` 保存到当前工作目录，禁止仅在对话中输出不落盘。
- **完整写作任务**：按顺序1→5依次加载维度文件落实初稿，随后**必须执行维度6（`06-generation-editor.md`）的全套校验**（黑名单→真实性→编辑三问→人写技术→叙事逻辑→伦理），否则视为未完成。
- **局部改写/校验任务**：可直接加载对应维度文件单独执行；改写后仍须执行维度6的统计性校验与编辑三问。
- **风格校验任务**：先对照「Literary DNA Summary」判断文本是否具备作者的世界观与核心机制，再用下方校验清单逐条核对。
- **种子文本仅作结构参照**：「种子文本库」（见第五节）是结构范式与语感基准，写作内容一律按规则全新生成；禁止改写原文句子、禁止套用原文句式骨架做词语填充、禁止原文人物与场景进入新作。

## 三、Common Failure Modes

> 以下为本风格最高频的五类失败。写作前后各对照一遍：避免"像作者但没有文学价值"。

### 失败1
**错误**：死亡段落写得比日常段落还长、还细。
**原因**：AI默认重大事件浓墨重彩；余华恰相反——死亡一句带过，前后日常工笔。
**修正**：死亡用一句平静陈述；把笔墨移到死亡前后的琐事（借糖、喂牛、纳鞋底）。

### 失败2
**错误**：叙述者跳出来议论（"这就是那个时代的悲剧"）。
**原因**：讲述人只讲述不评判，议论即破功，也是AI总结冲动。
**修正**：删掉议论；情绪交给动作（"腿开始发软"）与粗话（"乌龟王八蛋"）承担。

### 失败3
**错误**：结尾升华为"生命的意义在于……"。
**原因**：余华小说收在空镜头、歌谣或日常动作上，苦难不产生教训。
**修正**：结尾落在一个动作或田野景物上，允许唯一一处轻度诗化比喻。

### 失败4
**错误**：人物对话文绉绉、人人语汇相同。
**原因**：民间言说要求身份即语言，福贵不会说文人的话。
**修正**：按人物身份配语汇（农民口语、粗话、口头禅"完啦""他娘的"）；对话独立成段。

### 失败5
**错误**：状态速记式描写（"照得人脸上发青""把东西攥得发白"）。
**原因**：无主体、无过程的状态派发是AI高频指纹（黑名单A11）。
**修正**：物件写具体、状态补主体，或换成身体动作后果；无必要时直接删。

## 四、风格校验清单

写作完成后，逐条校验：

- [ ] 文本是否体现「Literary DNA Summary」的五项要点（看世界方式/人物选择/苦乐处理/核心机制/规避项）
- [ ] 文风基调是否符合「风格总纲」的核心原则
- [ ] 维度1：作者精神（调性、立场、情绪底色）是否遵循 `01-author-spirit.md`
- [ ] 维度2：母题与世界观是否遵循 `02-theme-worldview.md`
- [ ] 维度3：叙事结构机制是否遵循 `03-narrative-mechanism.md`
- [ ] 维度4：语言节奏与词句是否遵循 `04-language-rhythm.md`
- [ ] 维度5：表达技法与留白是否遵循 `05-expression-and-space.md`
- [ ] 维度6：`06-generation-editor.md` 的 A-F 六节校验是否全部执行并有实际删改
- [ ] 是否触犯任一维度的❌避免规则或🤖 AI特征规避规则
- [ ] 段落粒度是否存在跳跃（单句成段/对话独立成段与长段交错，非全程均匀段落）
- [ ] 是否存在三段式排比或工整对仗式总结
- [ ] 场景切换是否存在时间硬切（而非全程平滑衔接）
- [ ] 用词是否保持民间粗糙感（非精致书面词汇）
- [ ] 死亡/苦难段落是否保持平静陈述（无煽情、无升华）
- [ ] 叙事逻辑自检是否通过：称谓辈分、对话因果、设定一致性、时间数字均无矛盾

## 五、种子文本库（全局强制）

> **用法**：种子文本是原文的结构范式与语感基准，仅作段落功能、句长节奏、过渡与收束方式的参照；写作内容一律按规则全新生成，禁止改写原文。
>
> **结构参照约束**：①为目标段落选取结构最接近的种子，对齐其段落功能、句长节奏（±5字浮动）、段落粒度与收束方式；②成稿后与种子对照做语感校准，偏差时调整结构与节奏，不得借用原文内容。

### 种子1：开篇段（框架叙事入场 + 游荡者自述）

> 我比现在年轻十岁的时候，获得了一个游手好闲的职业，去乡间收集民间歌谣。那一年的整个夏天，我如同一只乱飞的麻雀，游荡在知了和阳光充斥的村舍田野。我喜欢喝农民那种带有苦味的茶水，他们的茶桶就放在田埂的树下，我毫无顾忌地拿起漆满茶垢的茶碗舀水喝，还把自己的水壶灌满，与田里干活的男人说上几句废话，在姑娘因我而起的窃窃私笑里扬长而去。
> ——第一章

**结构特征**：第一人称回忆开场（"我比现在年轻十岁的时候"） → 职业/身份一句交代 → 长句铺陈游荡细节，逗号连缀，弱比喻（"如同一只乱飞的麻雀"）收尾。句长递增，末句最长。

### 种子2：死亡陈述段（白描死亡 + 动作化悲痛）

> 老全说完这话，过了没多久就死了。老全死后脑袋歪到了一旁，我和春生知道他已经死了，互相看了半晌，春生先哭了，春生一哭我也忍不住哭了。
> ——第四章

**结构特征**：死亡以一句平静陈述完成（"过了没多久就死了"） → 尸体姿态的素笔白描 → 旁观者反应用动作写（"互相看了半晌""先哭了"），无任何抒情议论。全是短句，逗号连缀。

### 种子3：对话冲突段（口语对话 + 动作插入 + 内心独白）

> 家珍还是说："你跟我回去。"
> 我给了她两巴掌，家珍的脑袋像是拨郎鼓那样摇晃了几下。挨了我的打，她还是跪在那里，说：
> "你不回去，我就不站起来。"
> 现在想起来叫我心疼啊，我年轻时真是个乌龟王八蛋。这么好的女人，我对她又打又踢。
> ——第一章

**结构特征**：对话独立成段、短促重复（"你跟我回去"两次出现） → 暴力动作用弱比喻带过（"像是拨郎鼓"） → 讲述人跳出来自嘲忏悔（"乌龟王八蛋"），情绪由粗话承担。

### 种子4：时代荒诞段（黑色幽默 + 民间逻辑）

> 队长是个喜欢听道理的人，不管谁说什么，他只要听着有理就相信。……买来的人说："没有更大的了，只能一锅一锅煮了。"……有庆听了这话也嘻嘻笑，他说："要不钢铁没煮成，桶底就先煮烂啦。"谁知队长听了这话，眉毛往上一吊，看着我说："福贵，这小子说得还真对。你家出了个科学家。"队长夸奖有庆，我心里当然高兴，其实有庆是出了个馊主意。
> ——第五章

**结构特征**：荒诞事件（煮钢铁）一本正经地写 → 人物对话承担全部喜剧效果 → 讲述人补一句冷面点评（"其实有庆是出了个馊主意"），不解释笑点。

### 种子5：收束段（空镜头 + 轻度诗化 + 歌谣）

> 老人和牛渐渐远去，我听到老人粗哑的令人感动的嗓音在远处传来，他的歌声在空旷的傍晚像风一样飘扬，老人唱道：
> 少年去游荡，中年想掘藏，老年做和尚。
> 炊烟在农舍的屋顶袅袅升起，在霞光四射的空中分散后消隐了。……我知道黄昏正在转瞬即逝，黑夜从天而降了。我看到广阔的土地袒露着结实的胸膛，那是召唤的姿态，就像女人召唤着她们的儿女，土地召唤着黑夜来临。
> ——第十章

**结构特征**：人物动作收场（渐渐远去） → 歌谣独立成段作锚点 → 景物空镜头（炊烟、霞光、田野） → 全书唯一允许的轻度诗化比喻收尾，无总结、无升华、无议论。

## 六、边界说明

本指导基于《活着》单本书提取，余华在其他作品中的风格可能有变化（先锋期短篇更实验，《兄弟》更夸张荒诞，《文城》更抒情）。书内年代政治话术（土改、公社、食堂宣传语）属题材强制内容，仅在写对应年代时使用，不属于余华个人语言惯性。
