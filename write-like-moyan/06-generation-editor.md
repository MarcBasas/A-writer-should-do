# 维度6：生成约束与编辑校验

本维度不改写风格，只回答三个问题：**初稿哪里像AI？哪里不像莫言？哪里该删？**

## A. AI典型问题检测（全局黑名单，逐条校验）

> 写作时逐条校验，触发任一条即须改写。

### A. 句式黑名单

| 编号 | 禁止的AI典型句式 | 具体表现 | 替代策略 |
|:---:|---|---|---|
| A1 | 三段式排比 | "A在...；B在...；C在..."三段并列 | 用一句直白概括替代，或只保留一个具体场景；莫言式排比须失控延长至≥6项 |
| A2 | "不是A而是B"对比结构 | 用该句式推进论点 | 用直接陈述或具体经验替代 |
| A3 | 设问自答式推进 | "为什么...呢？因为..."（莫言的设问多为民间反问"什么老人？老妖怪！"，不作逻辑自答） | 用直接陈述、转述或场景叙述替代 |
| A4 | 工整对仗式总结 | "把A当成B""将A化为B"的对称总结句 | 用口语化直白表达替代；对偶仅用于场面空镜头（四字四句） |
| A5 | 过渡词模式化 | 每段开头都用"当然""不过""说到底"等过渡词 | 过渡词分散使用，至少30%的段落无过渡词直接跳跃（"当然"在莫言处是插话让步，不作段首过渡） |
| A6 | 拟人化修辞 | "胃开始抗议""时间在流逝"等AI式拟人 | 用直接身体感受替代（如"胃开始不舒服"） |
| A7 | 伪亲切模式 | 滥用"你"制造代入感（"你是否也..."） | 用第一人称讲述与"先生，"式倾诉替代 |
| A8 | 故作轻松语气 | "就这么简单""其实很容易""没什么大不了" | 用真实的困难描述替代 |
| A9 | "不"字定义法 | 用"不+形容词"定义判断（"不简单""不容易"） | 用具体描述替代（"需要反复尝试""花了三个小时"） |
| A10 | 强制因果句式 | "正是因为...所以...""由此可见..."的显性因果链 | 用语义自然承接替代，省略因果连接词 |
| A11 | "短直简"速记式描写 | 用极短致使结构直接派发状态，或用模糊物件、省略主体，如"照得人脸上发青""把东西攥在手里，攥得发白"——无具体过程与体验细节，也不承担叙事功能 | 把物件写具体、给状态补上主体，或替换为具体的身体/体验后果，无必要时直接删除 |
| A12 | 主题词借壳与金句回击 | 让虚构人物原样说出主题词或论点，或为人物安排滴水不漏的警句回击——现实中的人只按身份处境利益说话，完美金句一秒即被识破为AI | 人物只说符合其身份处境的话，主题词留给叙述者；回击宁可笨拙、平淡或缺席 |
| A13 | 句尾顿悟点评与缀饰 | 叙述或描写完成后，在句尾追加极短的论断、感悟或修饰，形成事实加顿悟、描写加缀饰的两段式，如两样钱都黑、一个馒头比天大、眉毛蜷起来像烧过的纸、手黑得发亮、吃得脸都肿——细节被强行点化成寓言，描写被强行拔高成抒情，是最高频的AI腔痕迹；同禁无叙事功能的过短状态句 | 默认整句删除句尾顿悟与缀饰，叙述在事实本身处停止；若该句承担伏笔或人物刻画等叙事功能，改写为具体过程、动作或台词，不得以独立短论断句的形式保留 |

### B. 用词黑名单

| 编号 | 禁止的AI典型用词 | 具体词汇 | 替代策略 |
|:---:|---|---|---|
| B1 | 精致书面词汇 | "信誓旦旦""固有认知""终极武器""毋庸置疑""综上所述""不言而喻" | 用日常口语化表达替代；叙述者可用土味四字格（火冒三丈、哭天抢地）替代精致书面词 |
| B2 | 对冲语气词过度使用 | "似乎""或许""大概""应该""可能"每篇超过3次 | 莫言用"仿佛/似乎/大约"承载半信半疑的转述，属主动用法可保留，但每篇合计不超过5次 |
| B3 | 模糊代词 | 用"东西""活""事"代替具体名词 | 用精确名词替代 |
| B4 | 单字形容词 | "腻""响""空""窄""快""大"等单字形容 | 用完整短语替代 |
| B5 | AI式刻意口语 | "跳脚""兜不住""挺久""还行""一堆""有货""有坑" | 用自然口语替代；莫言式口语为乡土词表（腚、嫚、拉呱、耍死狗） |
| B6 | 空洞断言词 | "迟早""必然""一定会""终将" | 用具体条件限定替代 |
| B7 | 精致形容词堆砌 | "深刻的""本质的""核心的""关键的"连续出现 | 每篇此类词不超过2个，用具体描述替代 |
| B8 | "某种程度上"式模糊限定 | "某种程度上""在一定意义上""从某种角度" | 直接删除或用具体程度替代 |

### C. 结构黑名单

| 编号 | 禁止的AI典型结构 | 具体表现 | 替代策略 |
|:---:|---|---|---|
| C1 | 完整起承转合 | "引入→经历→案例→辩证→总结→收束"的完整对称结构 | 允许结构松散、过渡突兀、结论松散；章节可停在动作或问句上 |
| C2 | 过于平滑的段间过渡 | 每段开头都与上一段自然衔接 | 须有至少2处跳跃或断层（莫言式硬切） |
| C3 | 均匀段落分布 | 所有段落长度相近（每段3-5句） | 单句成段与正常段落交错，单句成段占比≥15%，且至少1个500字以上展览长段 |
| C4 | 对称论证 | 论据与结论完美匹配 | 允许某些论据指向模糊结论，或结论缺乏充分论据（民间报应论悬空无据） |
| C5 | 过度类比 | 为每个观点都构造一个比喻 | 比喻从场面自然生发，每千字约2个，禁止为论点定做 |
| C6 | 信息均匀分布 | 每段信息密度相近 | 制造信息不对称：民俗展览段密度极高，死亡转述段几乎无信息 |

### D. 质感黑名单

| 编号 | 禁止的AI典型质感 | 具体表现 | 替代策略 |
|:---:|---|---|---|
| D1 | 刻意构造的比喻 | 为论点定做严丝合缝的寓言或比喻（如"名牌T恤""捷径的通行证"） | 比喻须从场面自然生发，喻体限定乡土/身体域，允许失配与无用细节 |
| D2 | 伪亲切代入 | 滥用"你"制造代入感 | 用"我"的第一人称讲述替代 |
| D3 | 故作轻松 | "就这么简单""没什么大不了" | 用真实困难描述替代 |
| D4 | 总结式收束泛滥 | 每篇都以"说到底""归根结底"式总结收束 | 以问句、动作、荒诞问答收束（"这算怎么回事呢？""犹如喷泉"） |
| D5 | 完美论证 | 每个论点都有充分论据，逻辑无懈可击 | 须允许至少1处论证留白或逻辑跳跃（多版本真相不裁决） |

### 莫言专项🤖规则（提取自《蛙》的[反AI]特征）

- 🤖 引号对话+对话逐句独立成段 ← 对抗：莫言全书引号为0 → 一律改为"某某说："冒号引导嵌入叙述流
  - 人写参照："姑姑脸一拉，道：你听谁说的？"（第二部二章）
- 🤖 死亡场面渲染铺陈 ← 对抗：莫言大事小写 → 死亡压缩为一句陈述+一个身体动作或一句遗言
  - 人写参照："尽管姑姑的船载着王胆和新生婴儿疾驰返航，但终究也未能挽救王胆的生命。"（第三部）
- 🤖 句长均匀（AI标准差通常<10） ← 对抗：句长极差≥60字 → 排比失控长句与≤5字定性短句并置
  - 人写参照：389字"有的……有的……"枚举句与"姑姑水淋淋地冲进家门。"8字段同书并置
- 🤖 情绪全程均匀、笑闹与悲凉之间有过渡 ← 对抗：喧闹与悲凉硬切相邻
  - 人写参照：婚宴闹剧直接接"婚礼早晨，阴气森森。乌云密布，雷声滚滚"（第二部二章）
- 🤖 单一权威叙事讲清一切 ← 对抗：转述链多版本并存
  - 人写参照：大爷爷之死两说并存且叙述者只声明"不可信"不删版本（第一部二章）
- 🤖 人名同义替换强迫症 ← 对抗：人名原样高频重复
  - 人写参照："姑姑"全书1194次，从不替换为"她""这位老人"

## B. 文学真实性检查（莫言专项）

- [ ] 是否复制作者表面语言（原文句子/人物/地名不得进入新作：姑姑、蝌蚪、王胆、陈鼻、高密东北乡、杉谷义人一律禁用）
- [ ] 是否缺少真实细节（每场景须有时间/地点/人名/物件锚点：莫言的锚点是具体数字与身体细节——"一米九""三万八千元""七十厘米身高"级别）
- [ ] 是否只有风格没有世界观（删掉土语与四字格后，是否仍有"人人混合体、判决悬置"的莫言式判断方式）
- [ ] 人物台词真实性（人物只说符合身份处境的话：乡村接生员不说哲学，农民不说书面语；无主题词借壳、无金句回击）
- [ ] 忏悔底子是否存在（全文至少一处叙述者自剖；核心执行者至少一场圣洁戏与一场疯狂戏）
- [ ] 核心意象是否闭环（意象≥3次出现且结尾变形为罪/恐惧/赎的载体）

## C. 编辑校验三问（成稿后逐段执行）

1. **删除什么？**（删解释——莫言的转述从不解释动机；删过渡——硬切处不加衔接句；删金句——人物嘴里的警句一律改笨拙；删冗余修饰——死亡段不得有任何修饰性渲染）
2. **哪里应该停顿？**（重大变故后直接切场面或切空镜头，不停留咀嚼；判断句后不急于补论据——"成了神了，成了魔啦！"后不再解释）
3. **哪里应该留白？**（结尾不升华；动机写七分——"也可以作别的解释"；最痛处不用情绪词，只留遗言与动作；历史判决以问句悬置）

## D. 人写模拟技术（全局强制，逐项落实）

| 编号 | 技术 | 具体操作 | 量化要求 |
|:---:|---|---|---|
| E1 | 思维跳跃注入 | 讲述中途插入1-2处某人闲事（发迹史、外号来历），用"我赶紧拉回思绪"式句子拉回 | 每篇至少1处跑题+拉回 |
| E2 | 质量不均制造 | 故意让1-2句写得粗糙（土话碎句、口头禅），保持人写的不完美感 | 每篇至少1句口语化碎句（如"纯属造谣！"） |
| E3 | 具体到不能再具体的细节 | 莫言式具体：身高体重、金额数字、药名清单、日期（"1953年4月4日""三万八千元""当归、山药、熟地、甘草"） | 每篇至少2处数字/清单级细节 |
| E4 | 允许跑题 | 1-2句偏离主题的话，然后自然拉回（与E1配合） | 每篇至少1处跑题 |
| E5 | 信息不对称制造 | 民俗展览段密度极高，死亡转述段几乎无信息 | 全文信息密度差异≥3倍 |
| E6 | 个人语言怪癖复现 | 复现高频习惯：转述句式"某某说："、"当然"插话让步、"仿佛"半信转述、人名原样重复 | 每篇"某某说："≥5次、"当然"≥2次 |
| E7 | 体验性细节优先 | 用身体动作、感官（腥冷的气味、凉森森的肚皮）、主观判断替代环境描述 | 体验性细节占比≥60% |
| E8 | 句长极差制造 | 最短句（≤5字）与最长句（≥80字）并置，极差≥60字 | 句长标准差≥15 |

## E. 叙事逻辑自检（独立于风格校验，初稿后强制执行）

- [ ] ①人物称谓与排行辈分一致（乡土宗族称谓尤须核对：姑姑/大爷爷/堂兄弟称谓链）
- [ ] ②对话内部无自相矛盾（转述链中"某某说"的内容与现场重现不得冲突，除非刻意设计为多版本）
- [ ] ③机构名称、证件、程序等设定全文一致（公社/卫生院/户口等制度名词前后统一）
- [ ] ④时间、年龄、金额前后自洽（跨越年代的叙述须核对人物年龄线与金额数字）
- [ ] ⑤意象出现次数与变形节点核对（核心意象≥3次且后期变形）

## F. 反模仿伦理

- 模仿解释世界的方法，不复制作者的经历：不得把莫言真实生平、高密东北乡真实人物、计划生育具体案例搬进新作
- 像莫言≠是莫言：世界观落点允许不同（可写其他历史洪流题材），"说书人讲述+忏悔底子+判决悬置"的方法必须一致
- 禁止风格炫技：目录式排比每篇≤2处，对偶空镜头句每篇≤3处，土语粗口以维度4词表门槛为限
