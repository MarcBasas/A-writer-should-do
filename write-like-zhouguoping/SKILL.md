# 写作指导：周国平风格（基于《人生哲思录》）

## 适用场景

本指导适用于需要模仿周国平写作风格的创作任务，包括但不限于：续写、仿写、风格化改写、风格校验。指导基于单本《人生哲思录》提取，覆盖该书的写作特征（语丝体格言+随感、思辨翻转、第一人称入场、悲观-超脱底色），未涵盖作者学术著作与长篇叙事散文的风格变化。

## Literary DNA Summary

> **最高优先级参考**：写作前必读。与维度文件冲突时，以本摘要的精神为准。

**1. 如何看世界**：精神本位——外在功利是表象，灵魂生活才是真实。用本质主义追问一切：惯以「所谓X」剥开现象，从"一个人"的存在处境起笔，平视言说，从不训诫。
**2. 如何选择人物/素材**：只选精神性的对象——哲人语录、自造寓言、私密而微小的个人经验（深夜读书、埋种子、坏记性）；拒绝社会新闻、统计数据与成功学话题。
**3. 如何处理痛苦/快乐/冲突**：淡悲观垫底，松弛超脱收场。承认虚无与苦难但从不沉溺，给出「有悲观垫底的执著」式合题，容纳矛盾，拒绝一劳永逸的答案。
**4. 核心表达机制**：格言短段（单句成段）与密实随感段交错；辩证翻转代替线性论证；「我」字入场再推及「我们」；抽象判断必须落回一个具象物（绿芽、园地、碑）。
**5. 生成时最需避免**：俯视说教与「你应该」口吻；鸡汤式乐观；总结升华式结尾；华丽辞藻与精致形容词；网络流行语；给出彻底解决方案或行动清单。

## 一、风格总纲

1. **格言为骨架**：以短段格言（单句成段）与密实随感段交错推进，段落粒度必须跳跃，禁止匀速。
2. **"我"字入场**：一切论断从"我"的经验、信念、困惑出发，再推及"一个人""我们"，平视言说，从不训诫。
3. **思辨翻转**：用辩证翻转代替线性论证——"貌似相反，实则相通""有悲观垫底的执著"，容纳矛盾，不给最终答案。
4. **透明书面语**：用朴素抽象词（灵魂、永恒、超脱、真性情）+ 具象比喻（园地、绿芽、碑、梦），不用华丽辞藻与精致形容词。
5. **悲观垫底，超脱收场**：情绪底色是淡悲观与松弛超脱的稳定混合；可以尖锐，但尖锐后必须回收。

## 二、执行顺序与文件索引

写作时须按以下顺序依次加载并执行六个维度文件。顺序遵循「定神→立意→布局→炼语→施技→校稿」的递进逻辑，前序维度的决策构成后续维度的约束前提：

| 执行顺序 | 文件 | 维度 | 职责 | 依赖前提 |
|:---:|---|---|---|---|
| 1 | `01-author-spirit.md` | 作者精神模型 | 确立冲淡温和×内在尖锐的调性、第一人称平视立场、悲观-超脱情绪底色 | 无（最先执行，为全文定调） |
| 2 | `02-theme-worldview.md` | 母题与世界观 | 确定精神价值母题、引文/寓言/个人体验素材、非对称取舍 | 依赖维度1确立的精神底色 |
| 3 | `03-narrative-mechanism.md` | 叙事结构机制 | 规划散点聚合的片段结构、格言-随感交替、辩证翻转与反高潮收束 | 依赖维度2确定的母题与立场 |
| 4 | `04-language-rhythm.md` | 语言节奏系统 | 控制格言短段与密实长段的交错、周氏高频词、判断前置与提问留白 | 依赖维度3确定的结构框架 |
| 5 | `05-expression-and-space.md` | 表达技法与留白 | 选择比喻判断句、反讽自嘲、翻新引用、自然意象与留白 | 依赖维度4确定的词句节奏 |
| 6 | `06-generation-editor.md` | 生成约束与编辑校验 | AI检测、真实性检查、编辑三问、叙事逻辑自检、反模仿伦理 | 最后执行，初稿成形后终检 |

### 执行方式

- **产出落盘**：写作产出须按母 Skill「写作产出落盘」规则执行，成稿以 `{文章标题}.md` 保存到当前工作目录，禁止仅在对话中输出不落盘。
- **完整写作任务**：按顺序1→5依次加载维度文件落实初稿，随后**必须执行维度6（`06-generation-editor.md`）的全套校验**（黑名单→真实性→编辑三问→人写技术→叙事逻辑→伦理），否则视为未完成。
- **局部改写/校验任务**：可直接加载对应维度文件单独执行；改写后仍须执行维度6的统计性校验与编辑三问。
- **风格校验任务**：先对照「Literary DNA Summary」判断文本是否具备作者的世界观与核心机制，再用下方校验清单逐条核对。
- **种子文本仅作结构参照**：「种子文本库」（见第五节）是结构范式与语感基准，写作内容一律按规则全新生成；禁止改写原文句子、禁止套用原文句式骨架做词语填充、禁止原文人物与场景进入新作。

## 三、Common Failure Modes

> 以下为本风格最高频的五类失败。写作前后各对照一遍：避免"像作者但没有文学价值"。

### 失败1
**错误**：全程温和匀速，没有一处锋利，也没有一处自嘲。
**原因**：只提取了"冲淡平和"的表面调性，丢掉了"内在尖锐"与情绪突转这一反AI的精神指纹。
**修正**：在触及根本问题处写1-2句骤然锋利的判断，随后立即回收；另留至少1处自嘲式弱点暴露。

### 失败2
**错误**：以格言堆砌代替论证，通篇短句飘在空中。
**原因**：只模仿了格言的形（短），没有随感段的密实与引文翻转作底。
**修正**：格言段与密实随感段交错；每个核心判断配一段引文翻新、寓言或个人经验佐证。

### 失败3
**错误**：结尾写成"所以我们应该……"的总结升华。
**原因**：AI式闭环冲动；周国平的收束是格言、俏皮或轶事式反高潮。
**修正**：末段改为一句格言、一个轶事或一句「罢了」式降调收束，把答案留给读者。

### 失败4
**错误**：抽象抒情悬在半空（"生命真美好啊"）。
**原因**：周氏判断必须落回具象物，这是其情绪表达的核心机制。
**修正**：每个抽象判断落到一个具象物上收束（绿芽、园地、瓦罐、灯）。

### 失败5
**错误**：引用名言只为佐证观点。
**原因**：作者引文必翻转或翻新其意（先赞赏，再"但仔细玩味"），平铺引用是AI习惯。
**修正**：引后翻转，或反其意而用之；自造轶事可冒充引文但不得注假出处。

## 四、风格校验清单

写作完成后，逐条校验：

- [ ] 文本是否体现「Literary DNA Summary」的五项要点（看世界方式/人物选择/苦乐处理/核心机制/规避项）
- [ ] 文风基调是否符合「风格总纲」的核心原则
- [ ] 维度1：作者精神（调性、立场、情绪底色）是否遵循 `01-author-spirit.md`
- [ ] 维度2：母题与世界观是否遵循 `02-theme-worldview.md`
- [ ] 维度3：叙事结构机制是否遵循 `03-narrative-mechanism.md`
- [ ] 维度4：语言节奏与词句是否遵循 `04-language-rhythm.md`
- [ ] 维度5：表达技法与留白是否遵循 `05-expression-and-space.md`
- [ ] 维度6：`06-generation-editor.md` 的 A-F 六节校验是否全部执行并有实际删改
- [ ] 是否触犯任一维度的❌避免规则或🤖 AI特征规避规则
- [ ] 段落粒度是否存在跳跃（单句成段占比≥20%，非全程均匀段落）
- [ ] 是否存在三段式排比或工整对仗式总结
- [ ] 段间是否存在零过渡跳跃（而非全程平滑衔接）
- [ ] 用词是否为透明书面语（非精致书面词汇堆砌）
- [ ] 是否出现至少1处「所谓X」「在我看来」「我相信」式入场
- [ ] 结尾是否为反高潮收束（格言/俏皮/轶事），而非总结升华
- [ ] 是否以种子文本为结构参照（段落功能、句长节奏、收束方式对齐，内容完全原创）

## 五、种子文本库（全局强制）

> **用法**：种子文本是原文的结构范式与语感基准，仅作段落功能、句长节奏、过渡与收束方式的参照；写作内容一律按规则全新生成，禁止改写原文。
>
> **结构参照约束**：①为目标段落选取结构最接近的种子，对齐其段落功能、句长节奏（±5字浮动）、段落粒度与收束方式；②成稿后与种子对照做语感校准，偏差时调整结构与节奏，不得借用原文内容。

### 种子1：开篇定义段（论点前置 + "一句话概括"入场）

> 我的人生观若要用一句话概括，就是真性情。我从来不把成功看作人生的主要目标，觉得只有活出真性情才是没有虚度了人生。所谓真性情，一面是对个性和内在精神价值的看重，另一面是对外在功利的看轻。
> ——真性情

**结构特征**：第一人称"一句话概括"开场 → 否定世俗目标 → "所谓X，一面是……另一面是……"定义展开。三句，句长递增。

### 种子2：引用翻新段（外部引用 + 反用其意）

> 肖伯纳说："人生有两大悲剧，一是没有得到你心爱的东西，另一是得到了你心爱的东西。"我曾经深以为然，并且佩服他把人生的可悲境遇表述得如此轻松俏皮。但仔细玩味，发现这话的立足点仍是占有，所以才会有占有欲未得满足的痛苦和已得满足的无聊这双重悲剧。如果把立足点移到创造上，以审美的眼光看人生，我们岂不可以反其意而说：人生有两大快乐，一是没有得到你心爱的东西，于是你可以去寻求和创造；另一是得到了你心爱的东西，于是你可以去品味和体验？
> ——不占有

**结构特征**：引名言 → 先赞赏（"曾经深以为然"） → "但仔细玩味"翻转 → "岂不可以反其意而说"翻新收束。四句，第四句最长且以问句收尾。

### 种子3：格言节奏段（超短句独立成段 + 情绪突转）

> 我是易朽的。
>
> 不过我不在乎。我兴致勃勃地打捞我的泡沫，收集我的痕迹。
> ——写作

**结构特征**：5字极短句独立成段 → 让步词"不过"突转 → 具象动词（打捞/收集）收束。段落粒度极端跳跃。

### 种子4：辩证让步段（让步 + 引文 + 合题收束）

> 我们不妨眷恋生命，执著人生，但同时也要像蒙田说的那样，收拾好行装，随时准备和人生告别。入世再深，也不忘它的限度。这样一种执著有悲观垫底，就不会走向贪婪。有悲观垫底的执著，实际上是一种超脱。
> ——悲观·执著·超脱

**结构特征**："不妨……但同时……"让步结构 → 引蒙田 → "有X垫底的Y"合题定义收束。四句，末句最短作判断收束。

### 种子5：轶事反讽段（虚构故事 + 俏皮递进收束）

> 对艺术家的一个忠告：慎勿与同行结婚。
>
> 进一步的忠告：慎勿结婚。
> ——婚姻

**结构特征**：冒号格言格式 → "进一步的忠告"俏皮递进 → 极短收束，无解释无总结。备选种子：「某生嗜书，读书时必专心致志……海德格尔叩门求访。某生毅然拒之门外，读书不辍。海德格尔怏然而归。」（读书——文言白话夹杂的虚构轶事）

### 结构参照约束（强制）

- **内容全新生成**：写作时先选取种子文本作为结构参照，但内容须按规则全新生成，禁止逐句改写原文、禁止套用原文句式骨架做词语填充。
- **对齐参数**：新段落对齐种子文本的段落功能、句长节奏（±5字浮动）、段落粒度与收束方式。
- **语感校准**：成稿后与种子文本对照，校验段落功能、句长分布与语气一致性；偏差时调整结构与节奏，不得借用原文内容。

## 六、边界说明

本指导基于《人生哲思录》单本书提取，周国平在其他作品（学术论著、纪实文学、叙事散文）中的风格可能有变化。本书为作者自编摘编，四编分类与"1./2."小节编号为编辑体例，仿写单篇文章时不采用该层级结构，仅继承条目内部的格言-随感交替节奏。本书电子书文本的半角标点为转制痕迹，写作时一律使用中文全角标点。
